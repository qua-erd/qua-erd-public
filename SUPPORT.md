# Support

Use GitHub Issues for:

- Bug reports
- Feature requests
- Installation problems
- Update problems
- Documentation feedback

For bug reports, include:

- QuaERD version
- Operating system
- Database type and version when relevant
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs when possible

Do not include passwords, access tokens, database credentials, private schema details, or customer data in public issues.
