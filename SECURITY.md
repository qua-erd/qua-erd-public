# Security Policy

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Open a minimal issue stating that you want to report a security vulnerability, or use the contact channel described on the official QuaERD website when available.

Include:

- QuaERD version
- Operating system
- Impact summary
- Reproduction outline
- Whether sensitive data is involved

## Supported Versions

Only the latest public release is actively reviewed unless otherwise announced.
