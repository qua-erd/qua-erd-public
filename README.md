# QuaERD

QuaERD is a database design tool for ER diagrams, DDL generation, documentation, code generation, MCP-based AI assistance, and CRUD administration tool generation.

This repository is the public distribution and support repository for QuaERD.

## Repository Purpose

This repository is used for:

- Downloading official binary releases
- Reading release notes
- Reporting bugs and feature requests
- Tracking known issues
- Sponsoring development
- Hosting updater metadata

The source code is not published in this repository.

## Downloads

Official binaries are distributed from GitHub Releases.

- Windows installers and update files will be attached to each release.
- Tauri updater metadata is stored under `updater/`.
- Do not download QuaERD binaries from unofficial mirrors.
