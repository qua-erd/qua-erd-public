# Troubleshooting

## Application Does Not Start

Check:

- The downloaded file is from the official GitHub Release
- Your operating system is supported
- Security software did not block the application
- You have permission to install applications

## Update Fails

Check:

- Network access to GitHub Releases or the official update endpoint
- The installed version
- Whether a proxy or security product blocks downloads

## Reporting Logs

When reporting a problem, remove sensitive information from logs before posting them publicly.
